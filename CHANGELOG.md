# Changelog

Each release's notes. The release build takes the newest section for the update notice on the Mac and on Linux, so keep each section short and written for people who use Sweeflow.

## 0.1.0

The first release.

- Mac apps stream to Linux, each window in a window of its own.
- Apps in launcher, Shared clipboard, Drag and drop files and Sound passthrough.
- Global menu on KDE Plasma.
- Mac shortcuts, with the ones you choose kept for Linux.
- Tested on CachyOS (KDE Plasma and GNOME), Omarchy, Ubuntu and Linux Mint.
